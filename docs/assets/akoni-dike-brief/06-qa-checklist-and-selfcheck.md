# Akọni & Dike brief, part 6: QA checklist, self-check, "Needs historian"

## 1. Anachronism and sensitivity checklist, as numbered QA items

This is the ASSET_BIBLE checklist plus the 8 SCRIPT guardrails, each with the **method** that verifies it. Methods: **S** = scripted check in `scripts/check-akoni-dike-art.mjs` (written by the asset-designer in A1; denylist of asset ids, tags and file names, SVG scans, size and CREDITS cross-checks); **V** = visual sweep (Playwright screenshots of every chapter at 360 x 640 and 640 x 360, a contact sheet of every sprite sheet and every panel, plus greyscale and deuteranopia passes); **C** = content lint of the JSON (dialogue, facts, barks); **H** = human review (historian, cultural reviewer, native speaker, heritage body, compliance). QA marks each item PASS or FAIL in `docs/qa/akoni-dike-report.md`. QA never edits source.

**Scope of A0 versus A1.** This phase (A0) delivers the brief only. The following are **A1 work and do not exist yet**, so in A0 the **S** items are marked "pending A1" rather than PASS: (a) `scripts/check-akoni-dike-art.mjs` (the scripted checks, with the allow list in item 1); (b) the `[H-nn]` ticket gate: `games/akoni-dike/content/review/tickets.json` plus a build check that fails the release build while any shipped asset references an open ticket or any fact, source or quiz item is `reviewed: false` (item 35); (c) `games/akoni-dike/src/audio/sfx-sets.json` and `sfx.test.ts` for item 43 (part 5 section 3.1); (d) `games/akoni-dike/assets/CREDITS.md`. Until they land, QA verifies the corresponding items by the V and H methods only.

**Matching rules for the scripted denylists (items 1, 2, 9, 16).** `check-akoni-dike-art.mjs` splits every asset id, file name, path segment, layer id and tag on `-`, `_`, `.`, `/` and camelCase boundaries into lowercase **whole tokens** and flags a token only when it **equals** a denylist word (or a listed multi-token phrase such as `iron-roof`). Substring matching is not used, so `company-carrier.svg` (tokens `company`, `carrier`), `cart` and `carts` do not hit `car`, and `profound` does not hit `ofo`. Allow list, kept in `scripts/akoni-dike-art-allowlist.json` as `{ token, scope, reason }` rows and reviewed by QA: `mask` is allowed in rival `*-accent` mask layers and SVG `<mask>` or `<clipPath>` elements (a technical colour-mask, never a face or ritual mask) but **not** as an asset id, file name or tag; `watch` is allowed only in `watch-post`, `watch-fire` and `watch-tower`; `bottle` only in `water-calabash` metadata if ever needed (default: not allowed); `plastic` and `phone` only under `ui/museum/` and `ui/learning/quiz-tablet*` (item 4 path rule). Any new allow-list row needs a reason and a reviewer. The denylist runs on ids, tags and file names, not on prose in the brief.
