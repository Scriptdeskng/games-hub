# Credits: `sabi-words` (Sabi Words)

All art is **made in-repo by the asset-designer (Claude)** from basic shapes and paths. Licence: project-owned (same as the repository). No traced, copied or downloaded artwork; no real logos, brands, clubs, players or people. Generator: `scripts/gen-sabi-words-art.mjs` (SVG, silent audio placeholders, voice manifest); CSS is hand-written in `words-art.css`; checkers: `scripts/check-sabi-words-art.mjs` (art, CSS urls, contact sheets in colour and greyscale) and `scripts/check-sabi-words-pack.mjs` (word packs; run alongside `npm run packs:check`). `npx svgo` was not available in the build environment: the generator already emits compact SVG (about 10 KB gzip for all SVG and CSS, 33 KB gzip including the six word packs).
